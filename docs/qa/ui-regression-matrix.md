## ROOT CAUSE

**The six Hidden Trail subpages rendered as raw HTML because of two compounding issues:**

1. **Missing CSS variables (primary)**: `var(--background)` and `var(--foreground)` were NOT defined in `:root`. All six pages AND `HiddenTrailShell` use these variables extensively. When CSS uses an undefined custom property, the browser silently ignores the declaration, causing ALL background/text colors to fall back to defaults.

2. **Missing utility classes (secondary)**: The pages use Tailwind-like utility classes (`grid`, `grid-cols-*`, `text-3xl`, `font-black`, `rounded-xl`, `gap-4`, `p-5`, `mb-8`, etc.) that were not generated by the project's SCSS. The project uses Bootstrap with `bs-` prefix and custom SCSS classes only, but the pages reference un-prefixed class names.

**Fix applied:**
- Added `--background: #{$bg}` and `--foreground: #{$text}` aliases to `emit-tokens` mixin in `_tokens.scss`
- Added `$radius-full: 999px` SCSS variable to `_tokens.scss`
- Created `src/styles/_utilities.scss` with all missing utility classes (grid, flex, gap, spacing, typography, sizing, borders, position, overflow, effects, transitions, responsive variants, animations)
- Imported `_utilities.scss` in `chapter-one.scss`
